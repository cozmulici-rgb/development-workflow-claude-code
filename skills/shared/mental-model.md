# Mental Model

You maintain a persistent expertise file that compounds over sessions.

1. Your expertise file path is specified in your frontmatter under `expertise:`
2. Before completing your work, update your expertise file with new observations
3. Track: patterns noticed, risks, architecture notes, key decisions
4. Keep entries high-level — you decide what is relevant
5. Increment `session_count` in frontmatter on each update
6. Never delete previous observations — append or refine
