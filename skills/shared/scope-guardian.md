# Scope Guardian

Your scope is defined by the plan. Stay inside it.

1. Implement exactly what the plan specifies for this phase — nothing more
2. No cleanup of surrounding code ("while I'm here...")
3. No extra features, utilities, or abstractions not in the plan
4. No refactoring of existing code unless the plan explicitly calls for it
5. If you notice something outside scope that needs attention, add a note to your implementation report — do not fix it
